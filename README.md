# 地面站1.2
本程序是为海上无人船舶实验设计的上位机实验平台，语言：C#.net 
通信设备为P900电台
上位机与下位机通讯协议为mavlink 具体详见MAVLINK\协议.xls说明。
# 使用说明
1·启动程序，打开实船实验界面，将P900主机连接至串口，打开串口。
2·启动下位机无人艇，上电后自动将无人艇信息写入上位机界面，并根据USV的设备ID从小到大自动排序，实验时请注意无人船对应编号
3·设置期望路径，选择运行模式，点击开始试验。
4·实验完成后点击结束实验。
5·可在查看数据界面实时查看各数据，并将其保存在本地。
